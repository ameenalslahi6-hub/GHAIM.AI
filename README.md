# Ghaim

موقع عربي ثابت لاستوديو إبداعي بالذكاء الاصطناعي، جاهز للنشر على GitHub Pages.

## التشغيل المحلي

افتح `index.html` مباشرة في المتصفح، أو استخدم أي خادم ملفات ثابت.

## النشر على GitHub Pages

1. ارفع الملفات إلى مستودع GitHub.
2. من إعدادات المستودع اختر **Pages**.
3. اختر النشر من فرع `main` ومن مجلد الجذر `/`.
